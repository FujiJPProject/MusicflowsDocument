# 機能定義書:ミキサー機能

[機能設計書概要へ](../Readme.md)

## 1. 機能概要

ミキサー機能は、MusicBlocksで作成した複数トラックの音量、左右定位、ミュート、ソロ、メーター表示などを管理し、曲全体の聴こえ方を整えるための機能群である。

初心者向けの初期版では、一般的なDAWの複雑なルーティングや詳細メーターを前面に出さず、まずは「各トラックの音量を調整する」「左右の位置を調整する」「一時的に消す・単独で聴く」「音量レベルを確認する」といった基本操作を優先する。

入力選択、出力選択、センド、リターン、インサートエフェクト、バスルーティング、サイドチェイン、RMS / LUFS / 位相 / スペクトラム表示は、基本作曲フローが完成した後に拡張する将来候補とする。録音機能を今回のスコープから外す方針に合わせ、録音待機は対象外とする。

- 実装機能
  - ボリュームフェーダー
  - パン
  - ミュート
  - ソロ
  - メーター表示
  - チャンネルストリップ
  - ピークメーター

- 今後導入予定機能
  - 入力選択
  - 出力選択
  - センド
  - リターン
  - インサートエフェクト
  - バスルーティング
  - サイドチェイン
  - RMSメーター
  - LUFSメーター
  - 位相メーター
  - スペクトラム表示

## 2.機能別目的一覧

| 機能名                       | 説明                                   | 目的                                                                     |
| :--------------------------- | :------------------------------------- | :----------------------------------------------------------------------- |
| チャンネルストリップ         | トラックごとの音量・EQ・エフェクト管理 | トラック単位の主要操作を1箇所にまとめ、編集しやすくする                  |
| ボリュームフェーダー         | トラック音量調整                       | 各トラックの音量バランスを整えられるようにする                           |
| パン                         | 左右定位調整                           | 音を左右に配置し、曲全体の広がりを作れるようにする                       |
| ミュート                     | 音を一時的に消す                       | 特定トラックを一時的に消して確認できるようにする                         |
| ソロ                         | 指定トラックだけ鳴らす                 | 特定トラックだけを聴いて調整できるようにする                             |
| 録音待機                     | トラックを録音対象にする               | 録音対象を指定するための機能だが、今回の打ち込み特化方針では対象外とする |
| 入力選択【予定】             | マイク、ライン、仮想入力など           | 将来的に録音や外部入力を扱う場合に、入力元を選べるようにする             |
| 出力選択【予定】             | マスター、バス、外部出力など           | 将来的に複数の出力先を管理できるようにする                               |
| センド【予定】               | リバーブ等へ音を送る                   | 複数トラックで共通エフェクトを使えるようにする                           |
| リターン【予定】             | センド先の音を戻す                     | 共通エフェクト処理後の音をミックスへ戻せるようにする                     |
| インサートエフェクト【予定】 | トラックに直接エフェクトを挿す         | トラック単位で音質補正や空間効果を適用できるようにする                   |
| バスルーティング【予定】     | 複数トラックをまとめて処理する         | ドラム群や伴奏群などをまとめて調整できるようにする                       |
| サイドチェイン【予定】       | 他トラックの音でエフェクトを制御する   | キックに合わせてベースやパッドの音量を変化させるなどの表現を可能にする   |
| メーター表示                 | 音量レベルを表示する                   | 音が大きすぎる、小さすぎる状態を視覚的に確認できるようにする             |
| ピークメーター               | 最大音量を表示する                     | 音割れしやすいピークを確認できるようにする                               |
| RMSメーター【予定】          | 平均音量を表示する                     | 体感上の音量バランスを確認できるようにする                               |
| LUFSメーター【予定】         | ラウドネスを測定する                   | 配信や書き出し時の音量基準を確認できるようにする                         |
| 位相メーター【予定】         | 位相問題を確認する                     | 左右の音の打ち消しや広がりの問題を確認できるようにする                   |
| スペクトラム表示【予定】     | 周波数分布を表示する                   | 低音・中音・高音の分布を視覚的に確認できるようにする                     |

## 3. 機能別利用シーン

| 機能名                       | 利用シーン                                                               |
| :--------------------------- | :----------------------------------------------------------------------- |
| チャンネルストリップ         | トラックごとの音量、パン、EQ、エフェクトをまとめて調整したいとき         |
| ボリュームフェーダー         | ドラムが大きすぎる、メロディが小さすぎるなど、音量バランスを整えたいとき |
| パン                         | メロディは中央、伴奏は左右に広げるなど、定位を調整したいとき             |
| ミュート                     | 一時的にドラムを消してコードやメロディだけ確認したいとき                 |
| ソロ                         | ベースだけ、ドラムだけなど、特定トラックの音を集中して確認したいとき     |
| 録音待機                     | 録音対象トラックを指定したいとき。ただし今回のスコープでは対象外         |
| 入力選択【予定】             | 将来的にマイクや外部入力を選びたいとき                                   |
| 出力選択【予定】             | トラックをマスター以外のバスや外部出力に送信したいとき                   |
| センド【予定】               | 複数トラックに同じリバーブをかけたいとき                                 |
| リターン【予定】             | センドしたエフェクト音をまとめて調整したいとき                           |
| インサートエフェクト【予定】 | 特定トラックだけにEQや空間効果を直接かけたいとき                         |
| バスルーティング【予定】     | ドラム全体や伴奏全体をまとめて音量調整したいとき                         |
| サイドチェイン【予定】       | キックに合わせてベースやパッドの音量を自動的に変化させたいとき           |
| メーター表示                 | 再生中に音量が適切か確認したいとき                                       |
| ピークメーター               | 音割れしそうな最大音量を確認したいとき                                   |
| RMSメーター【予定】          | 平均的な音量感を確認したいとき                                           |
| LUFSメーター【予定】         | 書き出し時のラウドネスを確認したいとき                                   |
| 位相メーター【予定】         | 左右に広げた音が不自然に打ち消されていないか確認したいとき               |
| スペクトラム表示【予定】     | 低音や高音が多すぎないか、周波数の偏りを確認したいとき                   |

## 5. ルール・制約

| 機能名                       | ルール・制約                                                                                                               |
| :--------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| チャンネルストリップ         | 初期版では音量、パン、ミュート、ソロ、簡易EQ、簡易エフェクトをまとめるUIとして扱う。詳細ルーティングは将来候補に分離する。 |
| ボリュームフェーダー         | 音量を上げすぎると音割れするため、メーター表示やピーク表示と連動させる。                                                   |
| パン                         | 初心者向けには左右定位を視覚的に示す。極端な設定でも音が不自然にならないよう説明を付ける。                                 |
| ミュート                     | ミュート状態は明確に色やアイコンで表示する。再生結果に即時反映する。                                                       |
| ソロ                         | 複数トラックのソロ指定を許可するかを仕様で統一する。ミュートとの優先関係を明確にする。                                     |
| 録音待機                     | 録音機能を今回のスコープから外すため対象外とする。                                                                         |
| 入力選択【予定】             | 録音や外部入力を扱う段階で追加する。初期版では非表示にする。                                                               |
| 出力選択【予定】             | 初期版では基本的にMaster出力固定とし、複雑な出力先選択は将来候補とする。                                                   |
| センド【予定】               | 空間系エフェクトとの連携が必要になるため、リバーブやディレイの共有利用を行う段階で追加する。                               |
| リターン【予定】             | センドとセットで扱う。初心者向けには「共通エフェクト音量」として表現してもよい。                                           |
| インサートエフェクト【予定】 | 初期版ではチャンネルストリップ内に簡易表示し、詳細なエフェクトチェーン管理は将来候補とする。                               |
| バスルーティング【予定】     | トラック数が増えるまでは不要。導入時はグループ化機能と関連付ける。                                                         |
| サイドチェイン【予定】       | 初心者には仕組みが難しいため、導入時はプリセットやテンプレートとして提供する。                                             |
| メーター表示                 | 音量レベルは色で状態を示す。緑は安全、黄は注意、赤はピーク超過などの表現を使う。                                           |
| ピークメーター               | 音割れの目安として表示する。初心者向けには「赤くなったら音量を下げる」など説明を付ける。                                   |
| RMSメーター【予定】          | 初期版では不要。ミックスや書き出し品質を高める段階で追加する。                                                             |
| LUFSメーター【予定】         | 配信音量基準などが関係するため、書き出し機能が整った後に検討する。                                                         |
| 位相メーター【予定】         | ステレオ処理や広がり調整が増えた段階で追加する。                                                                           |
| スペクトラム表示【予定】     | 初心者には情報量が多いため、導入時は簡易表示や説明付きにする。                                                             |
