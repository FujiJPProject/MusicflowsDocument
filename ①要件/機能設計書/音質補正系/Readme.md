# 機能定義書:音質補正機能

[機能設計書概要へ](../Readme.md)

## 1. 機能概要

音質補正機能は、Musicflows上で作成した各トラックの音を整え、聴きやすくするための機能群である。  
初心者向けの作曲アプリであることを踏まえ、初期段階では「音を整える」「不要な低域や高域を減らす」といった目的を達成しやすい機能を優先する。

そのため、MVPでは **EQ** と **フィルター** を中心に、難しい専門操作をそのまま露出するのではなく、プリセットや目的ベースのガイドと組み合わせて扱う。  
一方で、グラフィックEQ、パラメトリックEQ、エンハンサー、エキサイター、サチュレーションは、基本作曲フローが固まった後に導入を検討する将来候補とする。

- 実装機能
  - EQ
  - フィルター

- 今後導入予定機能
  - グラフィックEQ
  - パラメトリックEQ
  - エンハンサー
  - エキサイター
  - サチュレーション

## 2.機能別目的一覧

| 機能名                   | 説明                          | 目的                                                       |
| :----------------------- | :---------------------------- | :--------------------------------------------------------- |
| EQ                       | 周波数ごとの音量を調整する    | こもりや痛い帯域を抑え、音のバランスを整えられるようにする |
| グラフィックEQ【予定】   | 帯域別にスライダーで調整      | 直感的な帯域操作で音質補正を行えるようにする               |
| パラメトリックEQ【予定】 | 周波数、Q、ゲインを細かく設定 | 問題のある帯域をより正確に補正できるようにする             |
| フィルター               | ローパス、ハイパス等          | 不要な低域や高域をカットし、音を整理できるようにする       |
| エンハンサー【予定】     | 音の明るさ感を加える          | 音の抜けや明瞭感を高められるようにする                     |
| エキサイター【予定】     | 高域の倍音を加える            | 音にきらびやかさや存在感を加えられるようにする             |
| サチュレーション【予定】 | アナログ風の歪みを加える      | 音に温かみや太さを加えられるようにする                     |

## 3. 機能別利用シーン

| 機能名                   | 利用シーン                                                             |
| :----------------------- | :--------------------------------------------------------------------- |
| EQ                       | ピアノやシンセが少しこもって聞こえるので、帯域バランスを整えたいとき   |
| グラフィックEQ【予定】   | 細かい理論はわからないが、複数帯域を見ながら簡単に上下させたいとき     |
| パラメトリックEQ【予定】 | 特定の周波数だけをピンポイントで削ったり持ち上げたりしたいとき         |
| フィルター               | 低音の濁りを減らしたい、高音を丸くしたいなど、不要帯域を整理したいとき |
| エンハンサー【予定】     | 音が少し曇っているので、明るく聞こえる方向へ補正したいとき             |
| エキサイター【予定】     | 高域に抜け感やきらびやかさを加えたいとき                               |
| サチュレーション【予定】 | デジタルっぽい音を少し太く、温かくしたいとき                           |

## 5. ルール・制約

| 機能名                   | ルール・制約                                                                                                  |
| :----------------------- | :------------------------------------------------------------------------------------------------------------ |
| EQ                       | 初心者向けの初期版では、用途別プリセットや簡易プリセット名を用意し、細かい数値設定を必須にしない。            |
| グラフィックEQ【予定】   | 帯域数を増やしすぎると初心者が迷いやすいため、導入時は本数を絞るか簡易モードを用意する。                      |
| パラメトリックEQ【予定】 | 周波数、Q、ゲインの意味が理解しにくいため、ヘルプ表示やプリセット補助を前提にする。                           |
| フィルター               | ハイパス / ローパスの基本操作を優先し、名称だけでなく「低音を減らす」「高音を丸くする」といった説明を添える。 |
| エンハンサー【予定】     | 過剰に使うと不自然になりやすいため、初期値や適用上限を控えめにする。                                          |
| エキサイター【予定】     | 高域を強調しすぎると耳に痛くなるため、適用量を制限し、Before / After 比較をしやすくする。                     |
| サチュレーション【予定】 | 音量変化や歪みが強くなりすぎる可能性があるため、Dry / Wet や出力補正をセットで扱う。                          |
