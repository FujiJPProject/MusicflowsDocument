# 機能定義書:MIDI編集機能

[機能設計書概要へ](../Readme.md)

## 1. 機能概要

MIDI編集機能は、Musicflows上でメロディ、コード、ベース、ドラムなどの演奏データを視覚的に入力・編集するための機能群である。

初心者が楽器を弾けなくても作曲できるように、音程と長さを視覚的に扱えるピアノロール、クリック操作によるノート入力、リズムを整えるクオンタイズ、音楽理論を補助するコード入力・スケール補正・アルペジオ生成を中心に提供する。

一般的なDAWのMIDI編集機能は多機能で複雑になりやすいため、Musicflowsでは「置く」「動かす」「伸ばす」「消す」「整える」「補助を使う」という基本操作を優先し、初心者でも破綻しにくい作曲体験を目指す。

- 実装機能
  - ピアノロール
  - ノート入力
  - ノート移動
  - ノート長変更
  - ノート削除
  - ノート複製
  - ベロシティ編集
  - クオンタイズ
  - トランスポーズ
  - スケール補正
  - コード入力
  - アルペジオ生成
  - MIDI CC編集
  - ピッチベンド編集
  - アフタータッチ編集
  - ドラムエディタ
  - ステップシーケンサー

## 2.機能別目的一覧

| 機能名               | 説明                             | 目的                                                                     |
| :------------------- | :------------------------------- | :----------------------------------------------------------------------- |
| ピアノロール         | 音程と長さを視覚的に編集する     | 楽器が弾けないユーザーでも、音の高さと長さを見ながら作曲できるようにする |
| ノート入力           | MIDIノートを配置する             | クリックやステップ操作でメロディや伴奏を作成できるようにする             |
| ノート移動           | 音程・位置を変更する             | 入力した音の高さやタイミングを後から調整できるようにする                 |
| ノート長変更         | 音の長さを変更する               | 伸ばす音、短く切る音などを調整し、フレーズを作りやすくする               |
| ノート削除           | 不要な音を消す                   | 入力ミスや不要な音を取り除けるようにする                                 |
| ノート複製           | 音符をコピーする                 | 同じリズムやフレーズを効率よく再利用できるようにする                     |
| ベロシティ編集       | 音の強さを調整する               | 強弱を付けて、機械的すぎない演奏にできるようにする                       |
| クオンタイズ         | タイミングを拍に揃える           | 入力位置のズレを補正し、整ったリズムにする                               |
| ヒューマナイズ       | 少しズレを作り自然にする         | 完全に機械的な演奏を避け、自然な揺れを加える                             |
| トランスポーズ       | 全体の音程を上下する             | フレーズ全体を別の高さに簡単に移動できるようにする                       |
| スケール補正         | 指定スケール外の音を補正する     | 音楽理論がわからない初心者でも、外れた音を置きにくくする                 |
| コード入力           | コード単位で入力する             | コード理論を知らなくても、まとまった和音を配置できるようにする           |
| アルペジオ生成       | コードから分散和音を作る         | コードをもとに動きのある伴奏パターンを作れるようにする                   |
| ゴーストノート表示   | 他トラックのノートを薄く表示する | 他パートとの重なりや音域を確認しながら編集できるようにする               |
| MIDI CC編集          | モジュレーション等を編集する     | 音色変化や表現情報を調整できるようにする                                 |
| ピッチベンド編集     | 音程変化を編集する               | 音を滑らかに上下させる表現を追加できるようにする                         |
| アフタータッチ編集   | 鍵盤押し込み情報を編集する       | 対応音源での表現変化を扱えるようにする                                   |
| ドラムエディタ       | ドラム用のMIDI編集画面           | キック、スネア、ハイハットなどをリズムパターンとして編集しやすくする     |
| ステップシーケンサー | グリッドでパターンを作る         | 初心者がリズムや短いフレーズをマス目感覚で作れるようにする               |
| MIDIインポート       | MIDIファイルを読み込む           | 既存MIDIデータを取り込んで編集できるようにする                           |
| MIDIエクスポート     | MIDIファイルを書き出す           | 他ツールで利用できる形で演奏データを出力できるようにする                 |

## 3. 機能別利用シーン

| 機能名               | 利用シーン                                                 |
| :------------------- | :--------------------------------------------------------- |
| ピアノロール         | メロディやベースラインの音程と長さを細かく編集したいとき   |
| ノート入力           | 新しいメロディ、コード、ベース音を置きたいとき             |
| ノート移動           | 音程が合わない、タイミングがずれている音を直したいとき     |
| ノート長変更         | 音を伸ばしたり、短く切ったりしてフレーズ感を調整したいとき |
| ノート削除           | 不要な音や間違って入力した音を消したいとき                 |
| ノート複製           | 同じ音型やリズムを別の場所に繰り返したいとき               |
| ベロシティ編集       | 音の強弱を付けて、自然な演奏感を出したいとき               |
| クオンタイズ         | 入力タイミングを拍やグリッドに揃えたいとき                 |
| ヒューマナイズ       | 打ち込み感を少し減らし、自然なズレを加えたいとき           |
| トランスポーズ       | 作ったメロディを別の高さにまとめて移動したいとき           |
| スケール補正         | スケール外の音を避けながらメロディを作りたいとき           |
| コード入力           | コード名を選んで一括で和音を配置したいとき                 |
| アルペジオ生成       | コードをもとに分散和音の伴奏を作りたいとき                 |
| ゴーストノート表示   | 他トラックの音と重なりを見ながら編集したいとき             |
| MIDI CC編集          | モジュレーションなど、音色の変化を編集したいとき           |
| ピッチベンド編集     | 音程を滑らかに変える表現を作りたいとき                     |
| アフタータッチ編集   | 対応音源で押し込みによる表現変化を編集したいとき           |
| ドラムエディタ       | ドラムパターンを専用画面で作りたいとき                     |
| ステップシーケンサー | グリッド上で短いリズムやパターンを直感的に作りたいとき     |
| MIDIインポート       | 外部MIDI素材や過去に作ったMIDIを読み込んで編集したいとき   |
| MIDIエクスポート     | 作ったMIDIデータを他のDAWやツールで使いたいとき            |

## 5. ルール・制約

| 機能名               | ルール・制約                                                                                             |
| :------------------- | :------------------------------------------------------------------------------------------------------- |
| ピアノロール         | 初心者向けに、初期状態では必要最小限の音域と小節範囲を表示する。拡大縮小やスクロールは段階的に提供する。 |
| ノート入力           | スナップON時はグリッド単位で配置する。スケール補助ON時はスケール内の音を優先して入力できるようにする。   |
| ノート移動           | 移動後の位置が範囲外にならないよう制御する。スナップON時はグリッドに吸着させる。                         |
| ノート長変更         | 極端に短すぎる長さや負の長さにはできないようにする。初期版では固定単位の長さ変更でもよい。               |
| ノート削除           | 削除後は再生データに即時反映する。Undoで戻せる設計が望ましい。                                           |
| ノート複製           | 複製先が既存ノートと重なる場合の扱いを定義する。初期版では同位置複製後に移動させる仕様でもよい。         |
| ベロシティ編集       | 初心者向けに、数値入力よりもバーやプリセットで調整できるようにする。                                     |
| クオンタイズ         | クオンタイズ単位はグリッド設定に連動させる。適用前後の差が大きい場合はUndo可能にする。                   |
| ヒューマナイズ       | ランダム性を加えるため、適用量を小・中・大など簡易指定にする。過度なズレを避ける。                       |
| トランスポーズ       | 選択ノートまたはトラック全体に対して適用する。スケール補助との組み合わせ時は補正ルールを明確にする。     |
| スケール補正         | キー設定・スケール設定を基準に補正する。既存ノートを自動変換する場合は確認を挟む。                       |
| コード入力           | 初期版では主要な三和音・四和音を中心に提供する。複雑なテンションコードは将来候補でもよい。               |
| アルペジオ生成       | コード入力をもとに生成する。上昇、下降、上下などの簡易パターンから選べるようにする。                     |
| ゴーストノート表示   | 編集対象ではないノートは薄く表示し、誤編集できないようにする。                                           |
| MIDI CC編集          | 初心者向け初期表示では隠し、詳細編集として扱う。対応パラメータを限定する。                               |
| ピッチベンド編集     | 初期版では簡易カーブまたはプリセット中心にする。対応音源がない場合は無効化する。                         |
| アフタータッチ編集   | 対応音源が限定されるため、詳細編集扱いにする。未対応時は表示しない。                                     |
| ドラムエディタ       | ドラムトラック専用として表示する。音程名ではなくKick、Snareなどの名称で表示する。                        |
| ステップシーケンサー | 1小節または数小節単位のグリッド入力を基本とする。複雑なタイミング編集はピアノロール側に任せる。          |
| MIDIインポート       | 読み込み可能なMIDI形式やトラック数に制限を設ける。読み込み失敗時はエラー理由を表示する。                 |
| MIDIエクスポート     | 書き出し対象をプロジェクト全体または選択トラックから選べるようにする。                                   |
