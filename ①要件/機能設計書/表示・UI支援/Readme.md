# 機能定義書:表示・UI支援機能

[機能設計書概要へ](../Readme.md)

## 1. 機能概要

表示・UI支援機能は、Musicflowsで利用者が編集を試し、誤操作を戻しながら作曲を進められるようにするための機能群である。Undo/Redo、ドラッグ操作、ズーム、用語補足、ガイド表示を提供する。

アプリにログインし、自身が作成したプロジェクトを編集する利用者を対象とする。Undo/Redoは編集中のプロジェクト全体で操作順に扱い、画面ごとに別の履歴にはしない。

- 実装機能
  - Undo
  - Redo
  - ドラッグ操作
  - ズーム
  - 用語補足
  - ガイド表示

- 今後導入予定機能
  - なし

## 2.機能別目的一覧

| 機能名 | 説明 | 目的 |
| :--- | :--- | :--- |
| Undo | 最後に行った対象編集から逆順に元へ戻す | 誤操作や試した変更を戻し、安心して編集できるようにする |
| Redo | Undoで戻した編集を再適用する | 取り消した編集をやり直し、編集結果を比較できるようにする |
| ドラッグ操作 | 対象機能のルールに従ってノート・クリップ・トラックなどを操作する | 視覚的な操作で配置や値を調整できるようにする |
| ズーム | 対象の表示範囲や倍率を変更する | 曲全体の確認と細かい編集を切り替えやすくする |
| 用語補足 | 音楽・DAW用語の意味を初心者向けに説明する | 用語を理解しながら操作できるようにする |
| ガイド表示 | 機能の目的や操作方法を案内する | 作曲や編集を進めるための操作を理解しやすくする |

## 3. 機能別利用シーン

| 機能名 | 利用シーン |
| :--- | :--- |
| Undo | ノートを消し間違えた、音量やエフェクトを変更前へ戻したい、自動生成結果を取り消したいとき |
| Redo | Undoで戻した編集をもう一度適用したいとき |
| ドラッグ操作 | ノートやクリップの配置、トラック順、スライダーの値などを調整したいとき |
| ズーム | 曲全体の構成を確認したいとき、ノートやクリップを細かく編集したいとき |
| 用語補足 | スケール、ベロシティ、パンなどの意味を確認したいとき |
| ガイド表示 | 作曲の開始方法や、次に行う機能操作を確認したいとき |

例えば「ノート移動 → 音量変更 → リバーブ変更」と編集した場合、Undoは「リバーブ変更 → 音量変更 → ノート移動」の順で戻す。画面を切り替えても、この順番は変えない。

## 4. 各機能画面イメージ

画面イメージは未作成とする。作成する場合は参考図として扱い、画面の構成や表示項目が本文と異なる場合は、機能設計書本文を正とする。

## 5. ルール・制約

**Undo/Redo共通ルール**

Undo/Redoは、編集中のプロジェクト全体で操作順に扱う。画面を切り替えても、最後に行った編集から逆順に戻す。RedoはUndoで戻した編集を再適用する。

| 操作の種類 | Undo/Redoの対象 |
| :--- | :--- |
| ノートの追加・削除・複製・移動・音程・長さ・ベロシティ変更 | 対象 |
| クリップの配置・移動・削除・複製・分割・結合・延長、クリップ配置補正、セクション編集 | 対象 |
| トラックの追加・削除・複製・並び替え・名前・色の変更 | 対象 |
| 音源・プリセットの選択、音源パラメータ変更 | 対象 |
| 音量・パン・ミュート・ソロ・エフェクト設定変更 | 対象 |
| BPM・拍子・キー・スケール、曲名・制作メモの変更 | 対象 |
| コード入力、確定したコード検出結果の反映、自動生成、メロディ補正、MIDIクオンタイズ | 対象 |
| 再生・停止・一時停止・再生位置移動、ズーム、画面を開く・閉じる | 対象外 |
| プロジェクト保存・名前を付けて保存・自動保存、ファイル書き出し | 対象外 |
| プロジェクトの新規作成・切り替え・削除、プリセット保存 | 対象外 |

- 複数ノートなどをまとめて編集した操作は、1回のUndoで戻す。
- スライダーなどを1回ドラッグした変更は、1回のUndoで戻す。
- 自動生成1回の結果は、1回のUndoで戻す。
- Undo後に新しい編集を行った場合、それまでのRedoはできなくなる。
- 明示保存・自動保存ではUndo/Redo履歴を消さない。プロジェクトを開き直した場合は履歴を引き継がない。
- Undo/Redo後の未保存表示は、現在のプロジェクト内容と最後の明示保存内容との一致で判断する。自動保存の成功は、この判定とは分ける。
- 編集中のトラック削除はUndoの対象とする。プロジェクト一覧から行うプロジェクト削除は対象外とする。

履歴を保存するデータ構造、履歴の保持件数・容量、内部処理方式は後工程で詳細化する。現在工程では、上記の対象・操作単位・保存や開き直しとの関係を仕様とする。

| 機能名 | ルール・制約 |
| :--- | :--- |
| ドラッグ操作 | 対象、移動可能範囲、スナップ、重複の扱いは各機能のルールに従う。ドラッグによるプロジェクト内容の変更はUndo/Redo対象とする。 |
| ズーム | 表示のみを変更し、ノート・クリップなどの楽曲データは変更しない。対象画面の表示範囲・倍率は各機能のルールに従う。Undo/Redo対象外とする。 |
| 用語補足 | 専門用語には初心者に伝わる意味や操作目的を添える。具体的な表示位置・文言は後工程で詳細化する。 |
| ガイド表示 | 機能の目的と操作方法を説明する。具体的な画面配置・表示方法・文言は後工程で詳細化する。 |
