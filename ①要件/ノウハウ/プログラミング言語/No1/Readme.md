# 第1部：プログラミング言語の基礎構造

## 1. 言語仕様・処理系・実行環境

学ぶ内容：

- プログラミング言語仕様の役割
- コンパイラ、インタプリタ、仮想マシン、ランタイムの違い
- 標準ライブラリと言語機能の境界
- ソースコードから実行までの流れ
- 言語仕様で保証される動作と、処理系固有の動作

## 2. プログラミングパラダイムと言語設計

学ぶ内容：

- 命令型、手続き型、オブジェクト指向、関数型、宣言型
- ジェネリックプログラミング
- 並行・並列プログラミング
- マルチパラダイム言語
- 安全性、単純性、表現力、性能のトレードオフ

## 3. 構文・文法・評価規則・制御フロー

学ぶ内容：

- トークンと字句解析
- BNF・EBNFと文脈自由文法
- 具象構文木と抽象構文木
- 式と文の違い
- 演算子の優先順位と評価順序
- 条件分岐、反復、短絡評価
- パターンマッチと非局所的制御移動

## 4. 名前束縛・スコープ・名前解決

学ぶ内容：

- 識別子、宣言、定義、束縛
- レキシカルスコープ
- ローカル、クラス、モジュール、パッケージスコープ
- シャドーイング
- 名前空間と可視性
- オーバーロード解決
- importによる名前導入
