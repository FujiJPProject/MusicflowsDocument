# 第2部：値・関数・データ抽象化

## 1. 値・参照・同一性・可変性・引数渡し

学ぶ内容：

- 変数と値の違い
- 値意味論と参照意味論
- オブジェクト同一性と値の等価性
- 可変性と不変性
- エイリアシング
- 値渡し、参照渡し、参照値の値渡し
- 浅いコピー、深いコピー、ムーブ
- 共有と所有権移動

## 2. 関数・クロージャ・再帰・評価戦略

学ぶ内容：

- 第一級関数と高階関数
- ラムダ式と無名関数
- クロージャと自由変数
- 値捕捉と参照捕捉
- 正格評価と遅延評価
- 再帰と末尾再帰
- コールスタックとスタックフレーム

## 3. コレクション・イテレータ・ジェネレータ・遅延評価

学ぶ内容：

- 配列、リスト、マップ、集合
- mutableコレクションとimmutableコレクション
- iteratorとiterable
- generator
- lazy sequence
- 内包表記
- map、filter、fold
- ストリーム処理

## 4. データ抽象化・カプセル化・オブジェクトモデル

学ぶ内容：

- 抽象データ型
- 内部表現の隠蔽
- 表現不変条件
- クラスとオブジェクト
- コンストラクタ
- 継承と合成
- オーバーライド
- 動的ディスパッチ
- プロトタイプベースのオブジェクトモデル

## 5. インターフェース・トレイト・プロトコル・型クラス的抽象化

学ぶ内容：

- インターフェース
- トレイト
- プロトコル
- 抽象クラス
- mixin
- デフォルト実装
- 拡張メソッド
- 静的ディスパッチと動的ディスパッチ
- ad-hoc polymorphism
- 型クラスパターン
