# Musicflows方針設計書

## プロジェクトの目的

- このPJを通して下記技術の取得を目的とする
  - 専門知識が必要となるアプリの構築フローの確立
    1. アプリを作成する際にある程度専門知識が必要になる場合でもAIの活用や調査フローのドキュメント化していく
    2. これ以外で専門知識が必要になったアプリを作る際も1.で作成したドキュメント化された調査フローを確認しながら設計できる
    3. 短期間でそのアプリに必要な機能と自分が欲しいと思う機能を組み合わせたアプリを設計できる
  - コードで管理する技術の取得
    1. TerraformやDockerなどインフラや開発環境はコード化し、数回のコマンドで構築できるようにする
    2. 一度作ってしまえばほかのアプリを作る際も基本的な構成は流用できるため、アプリ開発に集中できる
  - UI/UXを考慮したアプリケーションの作成
    1. ユーザが直感的に使いやすいと感じるアプリを作成する技術を取得したい。(なかなか業務アプリの案件にかかわることが多いと取得しにくい)

## システム構成

- 開発環境としては Windows 上に WSL2 / Ubuntu を構築し、その上で Docker を利用する
  - 開発者の PC 環境に依存せず、Linux ベースの実行環境に近い状態で開発できるようにする
- バージョン管理、タスク管理、CI/CD は GitHub を中心に行う。
- インフラはTerraformで管理する
  - AWS リソースを手作業で作成するのではなく、コードとして管理することで、環境の再現性、変更履歴の管理、構成差分の確認をしやすくする。
