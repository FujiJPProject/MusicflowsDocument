# 用語集

[Readme](../../Readme.md)

## 背景

- 今回のPJにおいて専門用語が多くあるため用語集としてまとめておく
- ただ今回のコンセプトに初心者でもわかるをテーマにしているため用語集を見なくても分かるような

| フェーズ | ジャンル             | 用語                       | 意味                                                                                                                                             |
| :------- | :------------------- | :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| 要件     | プロジェクト管理機能 | プロジェクト               | ひとつの楽曲制作単位を指す                                                                                                                       |
| 要件     | プロジェクト管理機能 | 空プロジェクト             | 新規作成直後の、まだ楽曲データがほとんど入力されていないプロジェクト                                                                             |
| 要件     | プロジェクト管理機能 | 既存プロジェクト           | 保存済みで、後から編集・再開できるプロジェクト                                                                                                   |
| 要件     | トラック管理         | トラック                   | 楽曲を構成する音のまとまりを管理する単位。メロディ、コード、ドラムなどのパートごとに作成する                                                     |
| 要件     | トラック管理         | MIDIトラック               | 音程、長さ、タイミングなどのMIDIデータを入力・編集するためのトラック。メロディ、コード、ベースなどの打ち込みに使用する                           |
| 要件     | トラック管理         | AUX / リターントラック追加 | リバーブやディレイなどの共通エフェクトを複数トラックから送って使うための補助トラックを追加すること                                               |
| 要件     | トラック管理         | バストラック追加           | 複数トラックの音をまとめて処理するためのバストラックを追加すること。ドラム全体、楽器全体などをまとめて音量調整・エフェクト処理する用途で使用する |
| 要件     | トラック管理         | マスタートラック           | 楽曲全体の最終出力を管理するトラック。全トラックの音をまとめ、曲全体の音量や出力状態を確認するために使用する                                     |
| 要件     | 楽器・音源機能       | ギター                     | 弦を弾いて鳴らす楽器の音色。コード伴奏、アルペジオ、リフ、メロディなどに使う                                                                     |
| 要件     | 楽器・音源機能       | ピアノ                     | 鍵盤を押して鳴らす楽器の音色。コード確認、メロディ作成、伴奏作成などで使いやすい基本的な音色                                                     |
| 要件     | 楽器・音源機能       | ベース                     | 曲の低音部分を担当する楽器の音色。コードの土台を支え、楽曲全体の安定感やノリを作る                                                               |
| 要件     | 楽器・音源機能       | ドラム                     | キック、スネア、ハイハットなどでリズムを作る打楽器の音色。曲のテンポ感やビートを作る                                                             |
| 要件     | 楽器・音源機能       | シンセサイザー             | 電子的に音を作る楽器。波形、フィルター、エンベロープなどを調整して、メロディ、ベース、効果音、パッド音などを作る                                 |
| 要件     | 楽器・音源機能       | プリセット                 | あらかじめ用意された音色設定。初心者でも細かい音作りをせず、目的に合う音をすぐ選べるようにするための設定                                         |
| 要件     | 楽器・音源機能       | オシレーター               | シンセサイザーで音の元になる波形を作る部分。サイン波、ノコギリ波、矩形波などを選び、音色の基本的なキャラクターを決める                           |
| 要件     | 楽器・音源機能       | フィルター                 | 音の一部の周波数を削ったり通したりして、音の明るさ、こもり具合、柔らかさなどを調整する機能                                                       |
| 要件     | 楽器・音源機能       | エンベロープ               | 音が鳴り始めてから消えるまでの変化を調整する設定。音の立ち上がり、伸び、余韻などを決める                                                         |
| 要件     | 楽器・音源機能       | LFO                        | 音量、音程、フィルターなどを周期的に揺らすための低速の波。ビブラートや揺れる音色を作るときに使う                                                 |
| 要件     | MIDI編集機能         | ノート                     | MIDI上で扱う1つの音符データ。音の高さ、開始位置、長さ、強さなどの情報を持つ                                                                      |
| 要件     | MIDI編集機能         | ベロシティ                 | MIDIノートの音の強さを表す値。大きいほど強く、小さいほど弱く鳴り、演奏の強弱表現に使う                                                           |
| 要件     | MIDI編集機能         | クオンタイズ               | 入力した音のタイミングを拍やグリッドに揃える機能。ずれた演奏を整ったリズムに補正する                                                             |
| 要件     | コード・スケール支援 | コード                     | 複数の音を同時に鳴らした和音。曲の雰囲気や進行感を作る土台になる                                                                                 |
| 要件     | コード・スケール支援 | スケール                   | 曲で使う音の並びやルール。メジャースケール、マイナースケールなどがあり、メロディやコードを作る基準になる                                         |
| 要件     | コード・スケール支援 | アルペジオ                 | コードの音を同時に鳴らさず、順番に分散して鳴らす演奏方法。伴奏に動きを出すときに使う                                                             |
| 要件     | ミキサー機能         | ボリュームフェーダー       | 各トラックの音量を調整するつまみやスライダー。複数の音の大きさのバランスを整えるために使う                                                       |
| 要件     | ミキサー機能         | パン                       | 音を左右どちらから聞こえるようにするかを調整する機能。音の配置や広がりを作る                                                                     |
| 要件     | ミキサー機能         | ミュート                   | 指定したトラックの音を一時的に鳴らさないようにする機能。特定パートを外して確認するときに使う                                                     |
| 要件     | ミキサー機能         | ソロ                       | 指定したトラックだけを鳴らす機能。特定パートの音や編集内容を確認するときに使う                                                                   |
| 要件     | ミキサー機能         | チャンネルストリップ       | 1つのトラックに対する音量、パン、エフェクト、メーターなどをまとめて操作する領域                                                                  |
| 要件     | ミキサー機能         | ピークメーター             | 音量の大きさを視覚的に表示するメーター。音が大きすぎて割れていないか確認するために使う                                                           |
| 要件     | 空間系               | リバーブ                   | 音に部屋やホールのような響きを加えるエフェクト。音に奥行きや広がりを出す                                                                         |
| 要件     | 空間系               | ディレイ                   | 音を少し遅らせて繰り返すエフェクト。やまびこのような反復音を作る                                                                                 |
| 要件     | 空間系               | エコー                     | 音が遅れて返ってくるように聞こえる効果。一般的にはディレイに近い意味で使われるが、より自然な反響感を指すことが多い                               |
| 要件     | 空間系               | コーラス                   | 同じ音が複数人で鳴っているように、音に厚みや揺れを加えるエフェクト                                                                               |
| 要件     | 空間系               | ステレオイメージャー       | 音の左右の広がりを調整するエフェクト。音を広く聞かせたり、中央にまとめたりするために使う                                                         |
| 要件     | 音質補正系           | EQ                         | 特定の音域を上げたり下げたりして音質を調整する機能。低音、中音、高音のバランスを整える                                                           |
| 要件     | 音質補正系           | フィルター                 | 指定した周波数より高い音や低い音を削る音質調整機能。不要な低音や高音を整理するために使う                                                         |
